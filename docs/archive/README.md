# Arquivo histórico de documentação

Este diretório preserva auditorias, relatórios de QA/UX e notas de versões antigas que continuam úteis como evidência histórica, mas não são a fonte de verdade do estado atual do SFP.

Para operação e desenvolvimento atuais, consulte primeiro o README da raiz, `docs/ROADMAP-DEFINITIVO.md`, `docs/RELEASE.md`, `docs/FINANCIAL_CONTEXT_ENGINE.md`, `docs/UI_STYLE_OWNERSHIP.md` e `docs/REPOSITORY-HYGIENE.md`.

Os arquivos em `archive/` não devem ser usados para inferir comportamento atual sem conferir o código e o GitHub.
